## MVP scope
- Three-period financial input
- Documented financial ratios
- Financial Health Score
- Deterministic strengths and risks
- Executive dashboard
- DuPont analysis
- Scenario Lab
- Interactive Analysis Engine Map
- Print-friendly reporting

## Disclaimer
This project is an educational analytical tool. It is not a credit rating, investment recommendation, audit opinion or substitute for professional financial analysis.
